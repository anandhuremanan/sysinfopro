## Description (up to 10,000 characters)

SysInfo Pro is a system tool for people who use Windows every day, and especially for people who write code on it. It shows how your PC is doing at a glance, and gives you one-click tools for the problems that usually need three different programs.

The home screen shows a health score, CPU, memory, storage and battery, updating live. Below them are your favourite tools; every tool is one click away.

Tools for developers
• Ports: see which project and git branch opened each listening port, how long it has been running, and release a stuck port in one click.
• Dev caches: measure your npm, pnpm, pip, NuGet, Gradle, Maven, Cargo and Go caches, find old node_modules folders, and free the ones you pick.
• File locks: pick a file or folder that will not delete or move, see every program holding it open, and end the one in the way.
• PATH: find broken and duplicate PATH entries.

Tools for your disk
• Disk usage: find the largest folders and files on any drive.
• Disk growth: watch a folder and see which parts are growing, and how fast.
• Disk cleaner: clear temporary files and caches.

Tools for your system
• What changed: compare startup programs, installed software, listening ports and PATH with the last time you looked.
• Security check: antivirus, firewall, Windows updates, BitLocker, Secure Boot, User Account Control and more, in one read-only pass.
• Hardware specs: a full inventory down to each memory module, with a one-click report.
• Processes: sort running programs by memory, CPU or how fast their memory is growing, to catch a leak early.
• Startup programs, software versions, internet speed test, battery health and a ten-second stress test.

A widget that stays on top
Shrink the app to a small floating window showing CPU, memory, battery and the space left on each drive. It stays above every app, even through Show desktop, and an arrow appears the moment a drive starts filling up.

Private by design
No account, no analytics, no advertising. Everything the app reads stays on your PC. Light and dark themes follow Windows, or pick one in Settings.

## Submission options: restricted capability (runFullTrust)

SysInfo Pro is a desktop system utility. It reads hardware, disk, process, network and security information, ends processes the user chooses, and deletes cache folders the user selects. These require a full-trust desktop process.

## Notes for certification

No account or sign-in is needed; every feature works on first launch.

Actions that change the system only happen when the user asks: ending a process (Processes, Ports, File locks) and deleting folders (Dev caches and Disk cleaner, after a confirmation dialog). Only known cache folders and node_modules folders can be deleted.

Network use: the speed test contacts Cloudflare, or Measurement Lab if Cloudflare is unavailable; the Software tool fetches latest version numbers from nodejs.org, go.dev, endoflife.date and GitHub; a connection check contacts 8.8.8.8. The Store version does not check for or download its own updates.

Some security checks report "Unknown" on accounts that cannot read a setting; this is expected and not an error.
