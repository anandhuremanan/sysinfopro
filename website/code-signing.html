Code signing policy

SysInfo Pro by Probably Fine Labs · Last updated 28 October 2026

What is signed today

The Microsoft Store version is signed by Microsoft as part of the Store, and is the recommended way to install SysInfo Pro.

The program file on the GitHub releases page (sysinfopro-<version>.exe) is not code-signed yet, so Windows SmartScreen may warn the first time it runs. Signing it is planned; this page will say when it is.

Every release file is built by GitHub Actions from the public source code at github.com/anandhuremanan/sysinfopro, from a tagged release. Nothing built on a personal computer is signed.

Team roles

  • Committers and reviewers: anandhuremanan
  • Approvers, who approve each signing request: anandhuremanan

Changes from outside contributors are reviewed before they are merged, and every release is approved by hand before it is signed.

Privacy

SysInfo Pro has no account and no telemetry. It contacts other systems only for the checks described in the privacy policy: tests you start, such as the speed test and Network doctor, version lookups when you open Software, and a short internet connection check. The privacy policy lists every service it contacts and when.
